# The Pattern Issue Website  
## Goal

Launch a simple, elegant website that collects emails for the first crochet pattern.

This is Version 1.

The goal is not to build the final brand website.

The goal is to:
- Collect emails
- Build excitement
- Launch the first pattern on August 4

## Brand

The Pattern Issue is redefining how crochet patterns are experienced.

Instead of feeling like instruction manuals, every pattern should feel editorial, beautiful, premium, and collectible.

The website should feel like a luxury fashion brand—not a traditional crochet website.
