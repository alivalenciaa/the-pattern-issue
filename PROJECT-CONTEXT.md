Project Context – The Pattern Issue Website (Phase 1)

Overview

This website is the first version of The Pattern Issue, a modern crochet fashion platform. The current goal is not to build the entire long-term vision yet. The priority is to launch quickly with my first crochet pattern because there is already significant demand from my TikTok audience.

Many people have been asking for the pattern to my viral sequin crochet dress, so this website is primarily being built to release that pattern professionally.

The website should feel elevated, editorial, minimal, and fashion-forward—not like a typical craft or Etsy-style website.

⸻

Brand Direction

The Pattern Issue should feel more like a fashion publication than a traditional crochet business.

The inspiration comes from luxury fashion editorials, clean design systems, magazines, and modern brands.

The overall feeling should be:

* minimal
* timeless
* sophisticated
* feminine
* creative
* premium
* calm
* intentional

Crochet should feel like fashion.

⸻

Phase 1 Goals

The website should focus on doing a few things extremely well.

Primary goal:

Sell my first crochet pattern (the viral sequin dress).

This is the hero product of the website.

Everything on the homepage should naturally guide visitors toward learning about and purchasing this pattern.

⸻

Website Priorities

For this first version, prioritize:

* Beautiful homepage.
* Clean navigation.
* Product page for the first pattern.
* About page explaining the mission.
* Newsletter signup.
* A foundation that can easily grow later.

Do not build around multiple products yet.

Assume there is only one featured pattern.

⸻

Future Expansion (Keep Architecture Flexible)

The site should be designed so it can grow without needing a redesign.

Eventually I plan to add:

* more crochet fashion patterns
* editorial articles
* fashion trend reports
* crochet styling inspiration
* seasonal color inspiration
* tutorials
* newsletter content
* a blog/editorial section

Even further in the future, I plan to launch a separate materials brand called Hilo by Maria, which will include premium sequin yarn, crochet beads, stitch markers, hooks, and other tools.

However, none of this needs to appear in Phase 1.

The architecture should simply leave room for future expansion.

⸻

Target Audience

Women who appreciate:

* fashion
* handmade creativity
* elevated aesthetics
* modern crochet
* wearable garments
* DIY fashion

The audience is likely coming from TikTok after seeing my sequin dress.

Many visitors may be beginners or intermediate crocheters.

The experience should feel welcoming rather than intimidating.

⸻

Design Philosophy

Avoid making the website feel like:

* a craft store
* a hobby website
* Etsy
* scrapbook aesthetic

Instead, it should feel closer to:

* an editorial fashion website
* a luxury lifestyle brand
* an independent fashion publication

Lots of whitespace, thoughtful typography, clean layouts, subtle interactions, and beautiful photography.

The product should feel premium.

⸻

Long-Term Mission

The long-term mission is to inspire more people to create instead of only consume.

Crochet is more than a hobby—it is a creative practice, a meditative process, and a way to create beautiful wearable fashion.

The website should begin laying the foundation for that larger vision, while remaining focused on one thing today:

Launching the first sequin dress pattern in the most beautiful and professional way possible.
